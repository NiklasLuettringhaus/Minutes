- (event by coach) Run started headless (-A): user requested 100% autonomous BMAD pass, checking back end of day. No interactive elicitation possible.
- (decision by user) Scope fixed by user: menu-bar macOS app; record meetings; transcribe locally; infer speakers/title/tags; save .md; local models only; small clean UI to pick transcription model; menu bar click to start with colour state change; auto-detect Slack huddle / Teams meeting and prompt via notification.
- (event by coach) Host verified: macOS 26.6.2 (build 25G83), Darwin 25.6.0, Xcode 26.6, Swift 6.3.3, Apple M5, 24GB RAM, 10 cores. Target machine == build machine.
- (decision by coach) Transcription+diarization stack: argmaxinc/argmax-oss-swift (MIT) — WhisperKit (CoreML/ANE) + SpeakerKit (pyannote v4 community-1). Latest tag v1.1.0 verified via git ls-remote. Chosen over whisper.cpp: native Swift SPM, ANE-optimised for Apple Silicon, and diarization ships in the same package so no Python runtime.
- (decision by coach) System audio capture: CoreAudio process taps (AudioHardwareCreateProcessTap + private aggregate device), not ScreenCaptureKit. Rationale: audio-only, avoids Screen Recording permission and its menu-bar indicator.
- (assumption by coach) Dual-stream capture is the core design bet: mic stream = local user (known speaker, no diarization needed), system-audio tap = remote participants (diarize with SpeakerKit). Merging two labelled timelines beats diarizing one mixed stream and yields a guaranteed-correct 'me' label.
- (event by coach) Constraint discovered: 0 codesigning identities on this machine (security find-identity -v -p codesigning). TCC audio-capture consent is keyed to code signature, so ad-hoc signing is required and consent must be re-granted whenever the cdhash changes on rebuild.
- (event by coach) Constraint discovered: Apple Intelligence is opted out on this host (com.apple.CloudSubscriptionFeatures.optIn opted_out_buddy=1), so FoundationModels will report unavailable.
- (decision by coach) Metadata (title/tags/summary/actions) uses two backends: Apple FoundationModels on-device LLM when available, plus an always-available deterministic local extractor. FM is an enhancement, never a dependency — otherwise the app cannot title a meeting on this very machine.
- (event by coach) Meeting apps present: Slack com.tinyspeck.slackmacgap, Microsoft Teams com.microsoft.teams2, Chrome com.google.Chrome. Slack/Teams route call audio through Electron helper processes, so detection must match bundle-ID prefixes, not exact IDs.
- (event by coach) Known API traps captured for architecture: CATapDescription(stereoGlobalTapButExcludeProcesses:) sets exclusive=true (tap all EXCEPT listed) and must not be flipped; AVAudioEngine cannot be pointed at an arbitrary device so IOProc must be installed on the aggregate directly; kAudioAggregateDeviceTapAutoStartKey must be true; IOProc dispatch queue must not be nil on macOS 26+; kAudioProcessPropertyIsRunningInput listeners are unreliable so poll as well.
- (decision by coach) Product name: 'Minutes'. User supplied none; first draft invented 'Kokoro' which was arbitrary and exotic for a utility. Replaced with a plainly descriptive name held in a single constant so it is trivial to change.
- (change by coach) Applied doc_standards (bmad-review structure+prose lenses) inline rather than via parallel subagents, since subagent use was disallowed for this run. Trimmed flabby phrasing in Executive Summary, cut a precious closing line in Vision, tightened the secondary-audience paragraph.
