- (decision by user) MID-RUN USER DIRECTIVE (with FluidVoice screenshot): 'I like the way fluid voice sets up the models. Do something similar.' FluidVoice pattern to adopt: single window with grouped sidebar (Configure/Use/Activity/Help); a 'Quick Setup' checklist card whose rows carry state icon + title + one-line explanation + right-aligned control (dim 'Done' pill when satisfied, actionable button when not); completed rows de-emphasised; 'Run Onboarding Again' affordance; and a 'Test Playground' card that proves the pipeline end-to-end in-app.
- (decision by coach) Adopting the Test Playground is the highest-value part of the directive: macOS exposes no API to query system-audio-capture permission (see FR-42), so an in-app record-and-transcribe test converts an unanswerable question into an empirical one. Promoted from nice-to-have to a requirement.
- (change by coach) IA consolidated as a consequence: replaced the planned separate Settings window + Library window with ONE sidebar window (Setup / Transcription / Meetings / Detection / General). Net surface area roughly unchanged, so SM-C2 is respected; two windows collapsing into one is a simplification, not an addition.
