- (decision by coach) AD: tap IO uses AudioDeviceCreateIOProcID with a C function pointer and a global/Unmanaged context pointer, never the block+DispatchQueue variant. Consequence for design: the IOProc cannot capture Swift context, so the capture engine must pass an Unmanaged<Self> as the clientData refCon.
